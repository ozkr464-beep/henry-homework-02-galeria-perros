# 🐶 Galería de Perros — Homework 02

## 📌 Descripción del proyecto

Este proyecto consiste en una galería web de nueve fotografías de perros, desarrollada como parte de mi formación en Desarrollo Full Stack en **Soy Henry**.

Su objetivo es aplicar los fundamentos de HTML5 y CSS3 para construir una página web organizada, visualmente atractiva y adaptable a diferentes tamaños de pantalla.

**Año:** 2026

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura semántica del contenido.
- **CSS3:** estilos, colores y distribución visual.
- **CSS Grid:** organización de las fotografías en filas y columnas.
- **Flexbox:** distribución del contenido dentro de las tarjetas.
- **HSL:** definición de una paleta de colores.
- **Media Queries:** adaptación del diseño a diferentes pantallas.
- **Visual Studio Code:** editor de código.

## ✨ Características

- Galería de nueve fotografías de perros.
- Distribución mediante CSS Grid.
- Tarjetas con imágenes, títulos y descripciones.
- Efectos visuales al pasar el cursor.
- Variables CSS para gestionar colores.
- Diseño responsivo preparado para escritorio, tablet y móvil.
- Imágenes locales con atributos `alt` descriptivos.
- Preferencia de movimiento reducido contemplada en CSS.

## 📱 Diseño responsivo

El proyecto utiliza media queries para adaptar la distribución:

| Dispositivo | Ancho de pantalla | Columnas |
|---|---|---|
| Escritorio | Más de 900px | 3 |
| Tablet | De 601px a 900px | 2 |
| Móvil | Hasta 600px | 1 |

**Estado:** implementación realizada; pruebas visuales de tablet y móvil pendientes de certificación.

## 🚀 Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta `galeria-perros` en Visual Studio Code.
3. Abrir `index.html` en un navegador o utilizar la extensión Live Server.
4. Explorar las tarjetas y sus efectos visuales.

No requiere instalar dependencias, servidores externos ni bases de datos.
